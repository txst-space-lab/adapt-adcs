# ADAPT mission sources

Mission-level source material that ADCS work traces back to. Issues and design notes cite these files by slide number or meeting date.

| Path | What it is |
|---|---|
| [`overview/adapt-detail-overview-115.pdf`](overview/adapt-detail-overview-115.pdf) | The ADAPT Detail Overview deck (revision 115), the mission concept presented at the University Nanosatellite Program Mission Concept final event on 2026-07-17 |
| [`overview/adapt-detail-overview-115.md`](overview/adapt-detail-overview-115.md) | Text of the same deck, for searching and quoting |
| [`meetings/`](meetings/) | ADCS-relevant notes from team meetings, one file per meeting, named `YYYY-MM-DD-<topic>.md` |

## Conventions

- **The deck is a snapshot.** The working copy lives on the lab SharePoint. When a new revision is adopted, add it as a new pair of files with its revision number, and keep the old pair so that existing citations still resolve.
- **Slide numbers** are the numbers printed on each slide. Slide 4 is hidden in the deck, so the PDF has 41 pages: page *n* is slide *n* + 1 from slide 5 onward.
- **Meeting notes, not transcripts.** Recordings, full transcripts and official minutes stay on the lab SharePoint. Each note links to its recording, which needs a TXST login. This repo is public, so the notes here record decisions, technical points and action items. They don't record who said what, and they leave out discussion unrelated to ADAPT.
