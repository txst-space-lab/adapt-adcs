# University Nanosatellite Program material

Material from the University Nanosatellite Program (UNP), the AFRL program ADAPT was proposed to. It is general guidance for UNP teams, not specific to ADAPT; mission-specific sources are in [`../mission/`](../mission/). Issues and design notes cite these files by slide number.

| [`adcs-hardware-afrl-2025-2020.md`](adcs-hardware-afrl-2025-2020.md) | Text of the same deck, pointing to the workshop text for unchanged slides |

## Conventions

- **Decks are named by public release number** (`AFRL-YYYY-NNNN`, printed on every slide), which identifies the revision. Add a new revision as a new pair of files and keep the old pair so that existing citations still resolve. Only add material marked approved for public release; this repo is public.
- **Slide numbers** are the numbers printed on each slide. Slide 19 of the Hardware deck is hidden, so its PDF has 39 pages: page *n* is slide *n* + 1 from slide 20 onward.
- **Talk notes, not transcripts.** Notes record points made in a talk that aren't in its slides, without recording who said what.
