# AGENTS.md

## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on `txst-space-lab/adapt-adcs`, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

## Mission context

Mission source material (the ADAPT overview deck and ADCS-relevant meeting notes) lives in `docs/mission/`. Cite slides by their printed number and meetings by date. See `docs/mission/README.md`.

General ADCS guidance from the University Nanosatellite Program (UNP training decks and talk notes) lives in `docs/unp/`. See `docs/unp/README.md`.
